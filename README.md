
# Simple Visualizations for Probability\*

- Conditional Probability (cond.py)
- Marginal Probability (marg.py)
- Central Limit Theorem (clt.py)
- Law of Large Numbers (lln.py)

After installing the required packages `pip install -r requirements.txt`, just run `python main.py` to launch the application.
